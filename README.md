# 🎵 Music Gen

Генератор музыкальных треков в MIDI. Каждый запуск — один уникальный трек. Пространство возможных комбинаций — **больше 140 000**.

Не «случайные ноты», а гармонические прогрессии, проверенные временем: поп, баллады, джаз, андалузский минор. С басом, мелодией и разными тембрами.

## Что внутри

- **13 тональностей** — от C до B, включая минорные
- **15 гармонических прогрессий** — поп, баллады, джаз, блюз, эпик
- **3 темпа** — slow (60–80), medium (80–110), fast (110–140)
- **10 инструментов** — пианино, гитары, струнные, синты, пэды
- **4 стиля мелодии** — аккордовые тона, арпеджио, гаммы, редкие ноты
- **3 стиля баса** — корень, корень+квинта, ходьба
- **2 октавы мелодии**
